04 / MODEL TRANSPARENCY

Inside the experiment

Learn what this prototype does, and what its output can’t establish.

◈

How the pipeline works

  1. Image is uploaded or captured in your browser.
  2. Backend validates and resizes the image.
  3. ResNet18 produces scores for configured labels.
  4. The UI displays the highest scoring label as a model output.
⚑

Important limitations

  • Training used a small demo sample.
  • Model scores are not calibrated probabilities.
  • Performance has not been clinically validated.
  • Lighting, skin tone, image quality and dataset bias can affect outputs.
Educational prototype only. This tool cannot diagnose, rule out, or treat any condition. Do not rely on it for medical decisions. If you have a new, worsening, painful, spreading, bleeding, or concerning skin change, seek care from a qualified clinician.
